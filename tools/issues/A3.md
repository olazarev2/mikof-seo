**Что сломано.** `<h1>` отсутствует на 83+ страницах — проверено и в исходном HTML, и в отрендеренном DOM:

| Страница | h1 | h2 | h3 |
|---|---|---|---|
| `/` (и `/ru`, `/en`) | 0 | 16 | 0 |
| `/prices.shtml` | 0 | 5 | 0 |
| `/services.shtml` | 0 | 14 | 0 |
| `/diagnostica.shtml` | 0 | 5 | 0 |
| `/service/34`, `/service/38`, `/service/9`, `/service/70` | 0 | 7 | 0 |
| `/contact.shtml`, `/clinic.shtml`, `/question.shtml`, `/reviews.shtml`, `/articles.shtml` | 0 | 4–11 | 0 |

`<h1>` есть только на карточках врачей, статьях и лендинге SMILE Pro.

Дополнительно: `<h2>` используется для служебных элементов — «Autentificare», «Programarea la examinare», «Formulați întrebarea» (формы в шапке и футере). То есть на каждой странице сайта первые три заголовка второго уровня — это форма логина и форма записи, а не содержание страницы.

**Что сделать.**

1. В базовом layout вынести `<h1>` в обязательный слот; на каждой странице ровно один `<h1>`, текст — из поля названия сущности (услуга, раздел, врач).
2. Заголовки служебных блоков (формы логина, записи, вопроса, футер) перевести с `<h2>` на `<p class="...">` или `<div role="heading" aria-level="2">` вне основного контента — либо просто на `<span>` со стилем. В outline страницы они находиться не должны.
3. Внутри контента выстроить иерархию `h2` → `h3` (сейчас `h3` не используется нигде).
