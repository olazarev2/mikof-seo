> Задача **B4** из блока B — Разметка и представление (P1).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#b4 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** Нет ни визуальных крошек, ни разметки. Структура сайта плоская: со страницы `/service/34` нельзя подняться в «Диагностику», Google не видит иерархию.

**Что сделать.** Вывести крошки на всех страницах, кроме главной, и разметить:

```html
<nav aria-label="breadcrumb">
  <ol>
    <li><a href="/">Acasă</a></li>
    <li><a href="/diagnostica.shtml">Diagnostic</a></li>
    <li aria-current="page">Tomografie OCT</li>
  </ol>
</nav>
```

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "Acasă", "item": "https://mikof.md/" },
    { "@type": "ListItem", "position": 2, "name": "Diagnostic", "item": "https://mikof.md/diagnostica.shtml" },
    { "@type": "ListItem", "position": 3, "name": "Tomografie OCT" }
  ]
}
```

Уровни: диагностические услуги → «Diagnostic»; хирургия и заболевания → «Ce tratăm»; ЛОР → «ORL»; врачи → «Medici»; статьи → «Articole».
