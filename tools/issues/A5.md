> Задача **A5** из блока A — Технический фундамент (P0).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#a5 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.**

- В `sitemap.xml` **94 URL** при примерно **320 реальных**.
- Отсутствует главная страница.
- Отсутствует **любой** URL с `/ru` и `/en` — то есть две трети сайта не заявлены вообще.
- Отсутствуют `services.shtml`, `prices.shtml`, `diagnostica.shtml`, `doctors.shtml`, `contact.shtml`, `clinic.shtml`, `reviews.shtml`, `question.shtml`, `gallery.shtml`, `ore-de-primire.shtml` и все 17 карточек `/doctor/{id}`.
- Есть битый URL: `https://mikof.md/Atentie_deosebita_fata_de_pacienti_minori..shtml` (двойная точка) → **404**.
- У всех 94 записей `<changefreq>daily</changefreq>` и `<priority>0.8</priority>` — сигнал бессмысленный, для статей 2022 года заведомо ложный.
- Пространство имён `xmlns:xhtml` объявлено, но не используется — hreflang в sitemap не передаётся.
- `robots.txt` не содержит директивы `Sitemap:`. Сейчас там только:

```
User-agent: *
Disallow:
```

**Что сделать.**

1. Генератор sitemap перевести на обход всех публичных маршрутов во всех трёх локалях. Целевой объём — не менее 300 URL.
2. `lastmod` брать из `updated_at` записи, а не из даты генерации.
3. `changefreq` убрать полностью (Google его игнорирует) либо задать реалистично: `weekly` для прайса и главной, `yearly` для статей.
4. `priority` убрать или расставить осмысленно: 1.0 — главная, 0.9 — прайс и услуги-локомотивы, 0.5 — статьи.
5. Добавить hreflang-аннотации внутрь sitemap:

```xml
<url>
  <loc>https://mikof.md/service/34</loc>
  <lastmod>2026-08-24</lastmod>
  <xhtml:link rel="alternate" hreflang="ro" href="https://mikof.md/service/34"/>
  <xhtml:link rel="alternate" hreflang="ru" href="https://mikof.md/ru/service/34"/>
  <xhtml:link rel="alternate" hreflang="en" href="https://mikof.md/en/service/34"/>
  <xhtml:link rel="alternate" hreflang="x-default" href="https://mikof.md/service/34"/>
</url>
```

6. Убрать битый URL и добавить в генератор проверку: перед записью в sitemap URL должен отдавать 200.
7. Отдельный `sitemap-images.xml` для медиа `/storage/media/`.
8. `robots.txt` привести к виду:

```
User-agent: *
Disallow: /cabinet
Disallow: /forgot
Disallow: /captcha
Disallow: /online-register/success
Allow: /

Sitemap: https://mikof.md/sitemap.xml
Sitemap: https://mikof.md/sitemap-images.xml
```

Доступ GPTBot / ClaudeBot / PerplexityBot / Google-Extended **не закрывать** — цитирование в AI-ответах для клиники ценнее, чем защита текстов.

**Как проверить.**

```bash
curl -s https://mikof.md/sitemap.xml | grep -c '<loc>'        # ожидается: >= 300
curl -s https://mikof.md/sitemap.xml | grep -o '<loc>[^<]*' | sed 's/<loc>//' \
  | while read u; do c=$(curl -s -o /dev/null -w '%{http_code}' "$u"); [ "$c" != 200 ] && echo "$c $u"; done
# ожидается: пустой вывод
curl -s https://mikof.md/robots.txt | grep -i sitemap
```
