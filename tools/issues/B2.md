> Задача **B2** из блока B — Разметка и представление (P1).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#b2 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** Измерено на главной в Chrome, десктоп, быстрый канал:

| Метрика | Значение |
|---|---|
| Общий вес страницы | **4523 КБ** |
| Из них изображения | **4331 КБ** |
| CSS | 293 КБ (3 файла) |
| Изображений на странице | **116** |
| Из них с `loading="lazy"` | **0** |
| Из них с `width`/`height` | **0** |
| Файлов WebP/AVIF | **0** |
| Главный баннер `main_page_banner.png` | **683 КБ**, формат PNG |
| `load` | 3916 мс |
| TTFB | 164 мс (сервер быстрый — проблема исключительно в ассетах) |

Пример: три первых изображения из `/storage/media/` весят 117 КБ + 138 КБ + 73 КБ, все JPEG без ресайза под контейнер.

**Что сделать.**

1. `main_page_banner.png` → WebP + AVIF, ресайз под реальные брейкпоинты, целевой вес ≤ 120 КБ:

```html
<picture>
  <source type="image/avif" srcset="/images/banner-800.avif 800w, /images/banner-1600.avif 1600w" sizes="100vw">
  <source type="image/webp" srcset="/images/banner-800.webp 800w, /images/banner-1600.webp 1600w" sizes="100vw">
  <img src="/images/banner-1600.jpg" width="1600" height="600" alt="..." fetchpriority="high" decoding="async">
</picture>
```

2. `<link rel="preload" as="image" href="/images/banner-800.webp" imagesrcset="..." fetchpriority="high">` в `<head>`.
3. Всем `<img>` ниже первого экрана — `loading="lazy" decoding="async"`.
4. Всем `<img>` без исключения — атрибуты `width` и `height` (сейчас нет ни у одного; при медленной сети это даст скачки макета).
5. Пайплайн для `/storage/media/`: при загрузке в админке генерировать WebP и три размера, отдавать через `<picture>`.
6. Три CSS-файла (`app.css`, `new-app.css`, `responsive.css`) объединить и почистить; критический CSS первого экрана — инлайном.
7. Убрать битый путь `/../img/logo.png` — в разметке присутствует и корректный `/img/logo.png`, и вариант с выходом за корень.
8. Убрать дубли в `<head>`: `<meta charset>` и `<meta name="viewport">` выводятся по два раза.

Целевой бюджет главной: **≤ 1200 КБ**, PageSpeed Insights mobile ≥ 70.

**Как проверить.** PageSpeed Insights для `https://mikof.md/`, `/ru`, `/preturi`, `/service/35`; в консоли:

```js
[...document.images].filter(i => !i.width || !i.height).length   // ожидается 0
[...document.images].filter(i => i.loading === 'lazy').length    // ожидается > 80
```
