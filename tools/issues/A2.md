> Задача **A2** из блока A — Технический фундамент (P0).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#a2 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** `prices.shtml` — самая коммерческая страница сайта — после полного рендера в браузере содержит **1144 символа текста, 0 таблиц, 0 упоминаний «lei»**. В DOM есть только заголовок «PREŢURI din 01.09.2026», пояснение и селектор «Alegeți clinica». Цены подгружает Livewire после выбора города.

Последствия:
- Google может не дойти до контента за интеракцией — по запросам «preț operație cataractă Chișinău», «цена лазерной коррекции зрения Кишинёв» страница не ранжируется;
- AI-краулеры (GPTBot, ClaudeBot, PerplexityBot, Google-Extended) JavaScript не исполняют вообще — для них прайса не существует;
- конкурент pro-med.md по этим же запросам показывает цену прямо в сниппете.

**Что сделать.**

1. При первой загрузке `prices.shtml` рендерить на сервере прайс Кишинёва (город по умолчанию). Livewire оставить только для переключения между Кишинёв / Тирасполь / Рыбница.
2. Каждый город получает собственный индексируемый URL: `/preturi` (Кишинёв, canonical), `/preturi/tiraspol`, `/preturi/ribnita`. Селектор — обычные `<a href>`, а не JS-обработчик.
3. Разметить семантической таблицей:

```html
<h1>Prețuri servicii oftalmologice în Chișinău</h1>
<p>Preţuri valabile din 01.09.2026. Prețurile pentru diagnostic sunt indicate în lei, pentru ambii ochi.
   Prețurile pentru intervenții chirurgicale și tratament — în lei, pentru un ochi.</p>

<table>
  <caption>Prețuri diagnostic oftalmologic — Chișinău, valabile din 01.09.2026</caption>
  <thead><tr><th scope="col">Serviciu</th><th scope="col">Preț, MDL</th></tr></thead>
  <tbody>
    <tr><td>Consultația medicului oftalmolog</td><td>700</td></tr>
    <!-- ... -->
  </tbody>
</table>
```

4. Добавить блок «Ce include examinarea de 700 lei» — перечень обязательных и бесплатных исследований (сейчас он спрятан в скобках прайса и пациентом не читается). Это отдельная контентная задача, текст предоставляется заказчиком.

**Как проверить.**

```bash
curl -s https://mikof.md/preturi | grep -c 'lei\|MDL'    # ожидается: не менее 50
curl -s https://mikof.md/preturi | grep -c '<table'      # ожидается: не менее 1
```

Плюс в браузере с отключённым JavaScript страница должна показывать полный прайс Кишинёва.
