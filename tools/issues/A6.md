> Задача **A6** из блока A — Технический фундамент (P0).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#a6 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** Три независимых дефекта.

**1. Двойное HTML-экранирование.** В атрибут попадают сущности, уже прошедшие экранирование:

```html
<!-- /service/34 -->
<meta name="description" content="OCT, sau tomografia &amp;icirc;n coerență optică, este o investigație modernă care&amp;nbsp;vizualizează...">
<!-- /clinic.shtml -->
<meta name="description" content="Centrul &amp;quot;Microchirurgia ochiului&amp;quot; din Chişinău a fost fondat &amp;icirc;...">
<!-- /ru/service/34 -->
<meta name="description" content="ОКТ, или оптическая когерентная томография, &amp;mdash; это современное обследование...">
```

В выдаче Google это выведется буквально: `tomografia &icirc;n coerență`. Румынская версия страдает сильнее всего — вся диакритика (`î`, `ă`, `ș`) хранится в виде сущностей и превращается в мусор.

Причина: текст из редактора хранится с HTML-сущностями, дальше применяется `e()` / `{{ }}`, который экранирует `&` повторно. Нужен `html_entity_decode()` **до** экранирования.

**2. Слепая обрезка.** Все описания обрезаются ровно на 255 символах и получают `...`. Google показывает 155–160 символов, остальное отбрасывает; обрезка посреди слова выглядит как ошибка.

**3. Дубли и пустые.** Из 117 проверенных страниц уникальных описаний — 72. Одно и то же описание стоит на **31** странице, другое — на **12**. Пустые описания: `services.shtml`, `prices.shtml`, `diagnostica.shtml`, `doctor/1` и остальные карточки врачей.

**Что сделать.**

```php
// app/Support/Seo.php
public static function description(?string $manual, ?string $body, int $limit = 158): string
{
    if (filled($manual)) {
        return Str::squish($manual);
    }

    $text = html_entity_decode((string) $body, ENT_QUOTES | ENT_HTML5, 'UTF-8');
    $text = strip_tags($text);
    $text = Str::squish($text);                    // NBSP и повторные пробелы

    return Str::limit($text, $limit, '');          // обрезка по границе, без многоточия
}
```

Порядок операций обязателен: `html_entity_decode` → `strip_tags` → нормализация пробелов → обрезка.

В админке добавить ручные поля `meta_title` и `meta_description` для каждой сущности во всех трёх локалях; автогенерация — только фолбэк.

**Как проверить.**

```bash
curl -s https://mikof.md/service/34 | grep -o '<meta name="description"[^>]*>'
# в значении не должно быть подстрок "&amp;" и не должно быть "..." на конце
```

Плюс скрипт: собрать description со всех URL из `urls.txt`, посчитать дубли — уникальных должно быть не менее 90 %.
