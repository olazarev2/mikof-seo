> Полное ТЗ: https://mikof-seo-tz.vercel.app#b1 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** На 117 проверенных страницах — **0 блоков** `application/ld+json` и 0 микроданных. Для медицинской клиники это потеря всех типов rich results и, что важнее, отсутствие машиночитаемых фактов, которые цитируют AI-ответы.

**Что сделать.** Ниже готовые блоки. Вставлять в `<head>` через слот layout.

**3. `MedicalWebPage` + `MedicalProcedure` — на страницах услуг:**

```json
{
  "@context": "https://schema.org",
  "@type": "MedicalWebPage",
  "name": "Tomografia în coerență optică (OCT)",
  "url": "https://mikof.md/service/34",
  "inLanguage": "ro",
  "lastReviewed": "2026-09-03",
  "about": {
    "@type": "MedicalProcedure",
    "name": "Tomografie în coerență optică",
    "procedureType": "https://schema.org/NoninvasiveProcedure",
    "bodyLocation": "Retină, nerv optic, cornee"
  },
  "provider": { "@id": "https://mikof.md/#clinic" }
}
```

Для страниц заболеваний (`service/35` катаракта, `36` глаукома, `41` миопия, `43` кератоконус, `45` отслойка сетчатки) вместо `MedicalProcedure` использовать `MedicalCondition`.

**4. `FAQPage` — `question.shtml` и FAQ-блоки на страницах услуг:**

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "Cât durează operația de cataractă?",
    "acceptedAnswer": { "@type": "Answer", "text": "Текст ответа со страницы." }
  }]
}
```

Разметка должна отражать текст, реально видимый на странице.

**5. `BreadcrumbList` — на всех вложенных страницах** (см. B4).

**6. `Article` — на 45 статьях:**

```json
{
  "@context": "https://schema.org",
  "@type": ["Article", "MedicalWebPage"],
  "headline": "Заголовок статьи",
  "datePublished": "2025-11-30",
  "dateModified": "2026-02-13",
  "author": { "@type": "Person", "name": "ФИО врача", "url": "https://mikof.md/doctor/1" },
  "reviewedBy": { "@type": "Person", "name": "ФИО рецензента" },
  "publisher": { "@id": "https://mikof.md/#clinic" },
  "image": "URL изображения статьи",
  "inLanguage": "ro"
}
```

Множественный тип здесь обязателен: свойство `reviewedBy` определено schema.org для `WebPage`, а не для `Article` — на голом `Article` валидатор выдаст предупреждение.

**Не размечать** `AggregateRating` на основе отзывов с `reviews.shtml`, пока отзывы не привязаны к верифицируемым авторам — это нарушение правил Google и риск ручных санкций.

**Как проверить.** Каждый шаблон прогнать через `validator.schema.org` и Google Rich Results Test — 0 ошибок, предупреждения допустимы.
