> Задача **A4** из блока A — Технический фундамент (P0).
> Полное ТЗ: https://mikof-seo-tz.vercel.app#a4 · исходник: [`docs/tz-dev-2026-09.md`](../blob/main/docs/tz-dev-2026-09.md)

**Что сломано.** Разметка неполная на всех трёх версиях. Сейчас:

```html
<!-- на https://mikof.md/service/34 (RO) -->
<link rel="alternate" hreflang="ru" href="https://mikof.md/ru/service/34">
<link rel="alternate" hreflang="en" href="https://mikof.md/en/service/34">
<!-- нет ссылки на саму себя (ro) и нет x-default -->
```

Google требует, чтобы набор был **полным и взаимным**: каждая версия перечисляет все версии, включая себя. Без self-referencing разметка игнорируется целиком.

**Что сделать.** На каждой из трёх версий выводить одинаковый блок из четырёх строк:

```html
<link rel="alternate" hreflang="ro" href="https://mikof.md/service/34">
<link rel="alternate" hreflang="ru" href="https://mikof.md/ru/service/34">
<link rel="alternate" hreflang="en" href="https://mikof.md/en/service/34">
<link rel="alternate" hreflang="x-default" href="https://mikof.md/service/34">
```

Плюс исправить `og:locale` — сейчас на RU-версии тоже отдаётся `og:locale: ro_RO`. И `og:locale:alternate` содержит `en_EN`, такого локаля не существует, правильно `en_US` или `en_GB`.

**Как проверить.**

```bash
for u in https://mikof.md/service/34 https://mikof.md/ru/service/34 https://mikof.md/en/service/34; do
  echo "== $u"; curl -s "$u" | grep -o 'hreflang="[^"]*"' | sort;
done
# на каждом URL ожидается одинаковый набор: en, ro, ru, x-default
```
